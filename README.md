# Ultima VII (Exult) on the m9b SoC

Ultima VII, The Black Gate and Serpent Isle (with their add-ons, The Forge
of Virtue and The Silver Seed), as a program for the SoC in `../core`:
Exult 1.12.1, the open-source engine that plays the original games' data,
with the m9b in place of SDL. It runs from PSRAM, uses picolibc and its
libstdc++, and reads the games from the SD card through the core
firmware's SD driver and FatFs.

**Status:** it plays on the board (the Black Gate, in Trinsic, at 7–13
fps). In the host test harness
(`tools/host/`: the same Exult and port code on 32-bit x86 Linux, held to
the board's heap) both games play: Exult's game menu, the intros (with
the Guardian's speech), the menus, character creation, the openings in
Trinsic and on the Serpent Isle shore, conversations. Sound: with
Exult's Roland MT-32 packs, both games' music and sound effects as
recorded from an MT-32; without them, The Black Gate's AdLib music,
pre-rendered, and no sound effects (Sound).

Start it from the boot screen's browser (`EXULT.BIN` on the card), or with
`../core/tools/run.py build/exult.bin`. Exult's menu asks for the game.

**Input:** USB keyboards and mice on either USB port, with Exult's controls
(mouse to walk and use, keys as in Exult: `h` lists them); the terminal's
keys work too (arrows, Enter, Esc, Tab, Backspace, printable characters):
enough for the menus (Enter: the first game; Esc skips the intro; Up,
Enter: Start New Game; a name; Down, Down, Space: Journey Onward).

**License:** GPL v2 (`exult/COPYING`). The games themselves aren't free and
aren't in the repository; they come from an installed DOS version (the
`STATIC/` directories). `port/SDL2/` is under the zlib license and
`port/dlmalloc/` is public domain (MIT-0).

## Why Exult 1.12.1

Exult is the long-standing reimplementation of the Ultima VII engine; the
originals are 16-bit real-mode programs on Origin's own "Voodoo" memory
manager, with no source. 1.12.1 (January 2026) is the last release before
Exult moved to SDL3 and to a display of separately scaled layers (mouse
pointer, conversations, cutscenes): one 8-bit screen, as here.

It is C++17 (strings, containers, shared pointers, streams), and uses
exceptions for control flow (skipping cutscenes, quitting, optional files),
so it builds with libstdc++ for picolibc (Ubuntu's
`libstdc++-riscv64-unknown-elf-picolibc`, GCC 14.2's) with exceptions on:
their tables are about 300 KB of the image.

## Building and the SD card

`make` builds `build/exult.bin` (2.1 MB). `make B=build-prof
EXTRA="-DM9B_PROFILE -DPROF_SIZE=0x00200000u"` reports frames shown per
second, sound, frame copy and file read time, emulated misaligned accesses
and the heap's top every 5 s, and the PC profile every 15 s
(`../core/tools/prof.py ELF LOG`).

The game data goes in `data/` (`data/README.md` says what goes there).
The whole card, all the games with their data and music, is built in
m9b-system, which has this repository as a submodule:
`../sdcard/make_sdcard.sh` (see `../sdcard/README.md`) takes the data from
here. The scripts below add or replace files on a card in the board,
through the serial port.

The card, under `U7/`:
1. `tools/get_data.sh DIR` builds Exult's data files into DIR (it fetches
   their sources, Exult's `data/`, from GitHub).
2. `tools/put_data.sh --flx DIR --bg ULTIMA7 --si SERPENT`
   (the games' install directories) copies them, `exult.cfg` and the games'
   `STATIC/` directories: 412 files, 51 MB, about 14 minutes through the
   board (the Black Gate alone: 19 MB, 6 minutes). `--sfx PACKDIR` adds
   the sound effects packs (below), `--no-cfg` leaves the card's
   `exult.cfg` alone (Exult keeps its settings there).
3. The music: `tools/make_music.sh SOURCE OUTDIR --upload` (Sound).
4. `../core/tools/sdput/sdput.py put build/exult.bin EXULT.BIN` for the boot
   screen's browser.

Exult writes `U7/exult.cfg` back (settings), the game in progress to
`U7/GAMEDAT/BG|SI/` and the saves to `U7/SAVE/BG|SI/`.

## Memory

PSRAM (`../core/runtime/m9b.ld`): the image (2.09 MB) from `0x800000`, then
data and 52 KB of bss, the heap (5.83 MB; 5.71 MB in profile builds,
whose PC histogram takes 256 KB) and a 128 KB stack at the top. The heap
is Doug Lea's malloc (`port/m9b_malloc.c`): picolibc's lost about 540 KB
to holes and overhead. Exult assumed much more: starting the Black Gate
took 6.2 MB of heap. Now (the host harness, numbers from before the
floors change below):

| | Heap, most in use |
|---|---|
| Exult's game menu | 0.6 MB |
| The Black Gate's intro, menus | 1.3 MB |
| The Black Gate, Trinsic, a few minutes | 4.08 MB |
| Serpent Isle, the opening | 3.52 MB |

What changed (marked `M9B`):
- **Usecode** (the games' scripts, 1.5 MB of bytecode) was read whole at
  the start. Now each function's code is read from the file when a stack
  frame needs it, and dropped again, least recently used first and never
  while a frame runs it, to keep 192 KB at most
  (`usecode/ucfunction.cc`, `stackframe.cc`).
- **World shapes:** the frames read from `SHAPES.VGA` (7.3 MB on the disc)
  stayed in memory once read. Between frames of the main loop, when they
  take more than 384 KB, the least recently used shapes' frames are dropped
  (`shapes/vgafile.cc`, `shapeid.cc`, `exult.cc`).
- **Terrain:** each kind of chunk kept 256 `ShapeID`s of 16 bytes (4 KB,
  and Trinsic has 120 kinds); now 3 bytes a tile. The rendered floors
  (16 KB a chunk) are kept for 24 chunks, not 100 (`objs/chunkter.*`).

The rest: actors, objects, shape information, the display buffers, 28 open
files' buffers.

## Video

Exult draws into its 8-bit 320 x 200 surface (`Image_window`, scale 1,
Point, Fill: `exult.cfg`); `show()` copies it into one of three display
buffers, cleans it from the data cache and has the vertical-blank interrupt
show it (columns doubled, the 200 lines on 2 or 3 of the 480), loading the
palette (Exult's colors, as RGB565) at the same time.

`../core/tools/m9bctl.py shot OUT.png` takes a screenshot over the UART and
`m9bctl.py keys ...` types keys.

## Sound

Exult's mixer runs in the audio interrupt: it fills the next 256 frames of
the 48 kHz output at 24 kHz stereo (each frame held for 2). That plays
speech (the intros, from `U7SPEECH.SPC`/`SISPEECH.SPC`) and digital sound.
The games' music and sound effects are MIDI, played by a MIDI synthesizer,
none of which is built (too slow).

**Exult's Roland MT-32 packs** (from Exult's download page: the music,
`U7MusicOGG_1of2.zip` and `U7MusicOGG_2of2.zip`, and the sound effects,
`sqsfxbg.zip` and `sqsfxsi.zip`; Simon Quinn's recordings from a Roland
MT-32, the synthesizer the games were composed for) give both games their
music and sound effects. They aren't in the repository: unpack them into
one directory (PACKDIR).

- **Sound effects:** `sqsfxbg.flx` and `sqsfxsi.flx` (16-bit 22 kHz
  samples, 117 and 137 of them) go in `U7/EXULT/`, where Exult finds them
  by name (`put_data.sh --sfx PACKDIR`); its mixer plays them with the
  speech. Exult keeps the samples it played last in a cache of 6, and some
  are 300-550 KB, so the M9B build also holds the idle ones to 512 KB
  (`audio/Audio.cc`). In the host harness, the Black Gate's opening in
  Trinsic peaked at 4.15 MB of heap with the effects and the MT-32 music
  (4.08 MB without either).
- **Music:** `tools/make_music.sh PACKDIR OUTDIR [--upload]` converts the
  76 tracks (both games: Serpent Isle uses some of the Black Gate's, as
  Exult maps them) to 24 kHz 16-bit mono WAV files named as Exult names
  them (`05BG.WAV`, `SI01.WAV`, `ENDCR01.WAV`, ...), 75 minutes, 208 MB;
  `--upload` puts them in `U7/MUSIC/` (about 52 minutes through the board).
  The recordings' levels span 35 dB (-61 to -26 LUFS), so each track is
  brought to -18 LUFS (peaks at most -1 dBFS), as the other games' music,
  except the six that hold only ambient sounds (wind, birds, dungeons:
  `04BG`-`08BG`, `52BG`), which go to -30 LUFS to stay in the background.

**Without the packs**, `tools/make_music.sh U7DIR OUTDIR [--upload]`
renders The Black Gate's AdLib songs (`STATIC/ADLIBMUS.DAT`, `INTROADM.DAT`,
the AdLib songs in `ENDSCORE.XMI`; Flex archives, `tools/flexx.py`) with
libADLMIDI (`../core/tools/midirender`: Nuked OPL3, the Fat Man General
MIDI bank with the game's own timbres from `STATIC/XMIDI.AD` over it,
Miles' volume model; the songs use General MIDI programs, XMIDI.AD
replaces 11 of them and the drums) to 24 kHz 16-bit mono at a common
loudness, under the same names: 61 files, 57 minutes, 165 MB. Serpent
Isle has no music then, and there are no sound effects (the games' own
are MIDI, for AdLib with AIL's TVFX timbres, which libADLMIDI doesn't
play).

**Playback:** Exult's digital (Ogg) music path plays the WAV files: in the
M9B build its track functions (`audio/Midi.cc`) call `port/m9b_music.cc`,
which streams the file through a 64 KB ring (1.4 s: the heap is tight)
filled by the main loop (`SDL_PumpEvents`) and adds it to Exult's mix in
the audio interrupt. `exult.cfg` enables music with the "digital" driver
(no MIDI synthesizer is built, so none is started); the volume is Exult's
digital music volume (100 plays the file as it is), and the effects have
their own.

## The host test harness

`make host` builds `build-host/exult-host`, Exult and the port for 32-bit x86
Linux (gcc-multilib): the SoC's I/O registers are plain memory mapped at
their own addresses, a thread keeps the clock counter running, and the
harness plays the hardware's part from `SDL_PumpEvents` (vertical blanks,
audio halves written to `OUT/audio.wav`, USB keyboard and mouse reports
from a script, screenshots). It holds the heap to the board's (and reports
the most used), fills new memory with a pattern, counts open files, and
with `U7_HEAPPROF=1` lists the biggest allocations by where they were made.

```
U7_DATA=DIR U7_OUT=OUT U7_SCRIPT=SCRIPT build-host/exult-host
```

with DIR laid out as the card's `U7/` (`exult.cfg`, `EXULT/`, `BLACKGATE`
and `SERPENT` can be links to the game directories), and SCRIPT lines like
`4000 key 0x28` (time in ms, HID usage: Enter), `14000 text Avatar`,
`20000 move 90 -75`, `20500 click`, `30000 shot name`, `60000 quit` (see
`tools/host/host.cc`).

## Changes to Exult

Marked `M9B`:
- `usecode/ucfunction.*`, `stackframe.cc`, `ucinternal.cc`, `gamewin.cc`:
  usecode read as it runs (Memory).
- `shapes/vgafile.*`, `shapeid.*`, `exult.cc` (the main loop): world
  shapes' frames dropped when they take too much (Memory).
- `objs/chunkter.*`, `objs/chunks.h`, `gamerend.cc`: smaller terrain,
  fewer rendered floors, the flats painted straight from the terrain
  (Memory).
- `files/databuf.h`: reads straight from the stream's buffer
  (`istream::read`'s sentry cost more than the bytes).
- `exult.cc`: 320 x 200 at scale 1 by default.
- `audio/Audio.cc`, `AudioSample.h`: idle sound effects cached up to
  512 KB (Sound).
- `audio/Midi.cc`, `AudioSample.cc`: no Ogg Vorbis;
  `audio/midi_drivers/UnixSeqMidiDriver.h`: no Unix MIDI device.
